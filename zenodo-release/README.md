# 思想显影库（Thought Shadowing Library v3.0）

思想显影（实践学显影）是用**五段框架**对「方案／体系／理论」做结构提取的一种写法。它不解释、不评价、不处理思想的演变与争论，只回答一个问题：**这套东西在「存续」问题上，压成了一个什么样的判断。**

## 五段框架

1. **边界画在哪** —— 把什么当作存续单位
2. **把什么当最大威胁** —— 洪水（现象层／致因层）
3. **靠什么推动** —— 三种动能（突破性／稳定性／方向性）的承载物与配置
4. **用什么操作** —— 三类规则操作（源头改造／底线守护／共识凝聚），每项拆出「策略／承重件／断的条件／代价」
5. **压成一句什么判断** —— 结构判断，可独立引用，并给予命名

每篇另附**视野边界**（它看得见什么、看不见什么）、**剩余物**（这套语法没接住什么）与**厚度锚点**（指向原典的路标）。

## 关于版本演进

本库 v1.0（X-0001 至 X-0018，共 18 篇）已经作者判定在结构方法上存在系统性问题，**全部作废并重写**，原文保留于官网逐篇页并标注「已作废」，作为改写过程的记录。

v2.0 起改用 N 系列编号，确立现行的五段写法：① 段内补「定义权检查」与「已发生事实反证」；② 段区分「现象层／致因层（必须是动作）」；③ 段每个动能标注「缺它会怎样」；④ 段每个操作拆出「策略／承重件／断的条件／代价」；⑤ 段后新增「视野边界」。

**本版 v3.0** 是对 N 系列五篇的再次全面重写：判断句一律改为更直白、可被非专业读者直接抓住的表述，各段的「策略／承重件／断的条件／代价」进一步收紧，并新增 N-0005 论语一篇。

## 三条边界（本库不做什么）

1. **不评价** —— 不判断哪套思想更高明，只还原不同边界预设下的结构差异
2. **不替代原典** —— 显影是入口不是出口，厚度锚点只是指向原典的路标
3. **不用内部黑话** —— 正文一律使用对外公共语（三种动能／三类规则操作），不写三浪三元
